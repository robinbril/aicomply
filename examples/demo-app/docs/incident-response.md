# Incident response

Severity levels S1 to S3. S1 (personal data breach or discriminatory output at scale): the CISO
is paged, the DPO assesses notification to the Autoriteit Persoonsgegevens within 72 hours, and
the screening assistant is disabled until the root cause is fixed. All incidents get a post-mortem
in `docs/incidents/` within ten working days.
